🎯 HOW TO USE:
═════════════════════════════════════════════════════════════════

PATH 1: Claude.ai (Fastest - 0 min setup)
──────────────────────────────────────────
1. Go to: https://claude.ai
2. Copy any script from ai-lab-claude/
3. Paste into Claude
4. Ask: "Explain this code"
5. Learn interactively
✅ FREE, NO SETUP

PATH 2: Ollama Local (Free - 10 min setup)
────────────────────────────────────────────
1. brew install ollama
2. ollama pull mistral
3. ollama serve
4. python ai-lab-ollama/[MODULE].py
✅ FREE, OFFLINE, HANDS-ON

PATH 3: Anthropic API (Professional)
─────────────────────────────────────
1. Get API key: https://console.anthropic.com/account/keys
2. cd ai-lab-claude
3. Edit file: API_KEY = "sk-ant-v4-..."
4. python [MODULE].py
✅ BEST QUALITY, SMALL COST (~$1-2)
