# Daily Mentor Protocol

At each return:
1. Show current readiness snapshot.
2. Give exactly one primary task.
3. Define what a good answer looks like.
4. Wait for the user's answer/work.
5. Grade it against architect-level criteria.
6. Explain gaps.
7. Assign reinforcement only where needed.
8. Update Project 1 knowledge/reference.
9. Move to the next competency.

## Modes
- Architecture mode
- Coding mode
- Concept drill
- Case-study mode
- Mock interview
- Resume/job application mode

The user can switch modes explicitly.
