# Interview Preparation

## Four interview modes
1. Concept explanation
2. Whiteboard/system design
3. Live coding
4. Behavioral/leadership

## Answer framework
Definition → why → architecture → trade-offs → failure modes → metrics → production example.

## Coding rule
Every major concept in Project 1 must eventually have a 15–30 minute Python implementation drill in the Quick Reference.

## Mock interview loop
Question → answer → score → missing points → corrected answer → repeat under time limit.
