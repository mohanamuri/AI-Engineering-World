# AI Security & Governance

## Must-know threats
Prompt injection, indirect prompt injection, data leakage, excessive agency, insecure tool use, model supply-chain risk, sensitive-data exposure and tenant isolation failures.

## Controls
Least privilege, tool allowlists, input/output validation, secret isolation, data classification, retrieval ACL filtering, audit logs, human approval for high-impact actions and red-team evaluation.

## Architect interview question
How would you prevent an agent from being manipulated by a malicious document retrieved from an enterprise knowledge base?
